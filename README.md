# FeedbackIQ — AI-Powered Product Feedback Analyser

FeedbackIQ is a Java-based web application that analyses customer reviews to identify feedback themes, understand sentiment, prioritise issues, and generate recommendations for improving customer experience.

The application provides an interactive Spring Boot dashboard and supports Gemini AI analysis with a rule-based fallback when AI analysis is unavailable.

## Features

- **Multi-Theme Detection:** Identifies multiple feedback themes within a single customer review.
- **Theme-Based Sentiment Analysis:** Analyses sentiment for individual themes, helping distinguish positive and negative feedback in the same review.
- **Feedback Analysis Dashboard:** Displays review summaries, sentiment distribution, detected themes, and analysis results.
- **Issue Prioritisation:** Assigns priority scores to feedback themes to highlight issues that may need attention.
- **Actionable Recommendations:** Provides suggestions based on identified feedback and prioritised themes.
- **Gemini AI Integration:** Supports AI-powered review analysis when the API is configured and available.
- **Rule-Based Fallback:** Provides an alternative analysis method when Gemini AI is unavailable.
- **CSV Export:** Allows users to export analysis results through the dashboard.
